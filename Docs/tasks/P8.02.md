## 1. Analysis

**Goal:** a working React + TypeScript SPA in `taiji_ai/web/` that talks to the FastAPI backend, builds to
`web/dist` (served by FastAPI, P8.01), with lint, type-check and unit tests wired up; first page = system status
from `GET /api/health` (replaces the old Streamlit page).

**In scope:** project files, router, TanStack Query, typed API client with the backend error format, layout,
status page, 404 page, dev proxy to the API, Vitest + Testing Library tests (T-WEB-01 + client tests), ESLint,
build, serving through FastAPI, supply-chain settings, docs/notices/gitignore.
**Out of scope:** domain pages (P8.03+), charts (P8.08), Playwright (P8.15), `tools/check.ps1` (P0.05 — will call
`pnpm lint/typecheck/test`; noted there).

**Environment:** Node v24.12.0, pnpm 11.10.0.

**Package findings (npm registry, 2026-11-14):**
- Latest: react/react-dom 19.3.1, react-router 8.5.1 (node ≥ 22.22), @tanstack/react-query 5.107.1, vite 8.3.8,
  @vitejs/plugin-react 6.3.0, vitest 5.1.0 (node ^24), eslint 10.14.0, typescript-eslint 8.72.2, all MIT.
- **typescript-eslint peer: `typescript >=4.8.4 <6.1.0`** → use TypeScript **6.0.x**, not 7.0.2.
- **jsdom 30/31 require node ≥ 24.15** (we have 24.12) → use **jsdom 29** (node ≥ 24.0).
- Supply chain: several latest versions were published days ago → set pnpm `minimumReleaseAge` = 7 days
  (`pnpm-workspace.yaml`), declare caret ranges, let pnpm pick versions old enough; lockfile committed.

**API contract consumed:** `HealthResponse` from `api/routers/health.py` (status, version, models{ok,
verified_at_startup, entries[{name, role, sha256_prefix}], error}, database{ok, migrations, error}, web_build);
errors `{error:{code, message, details?}}`. Types hand-written for now; follow-up: generate from
`/api/openapi.json` when more endpoints exist (P8.03).

**Constraints:** API on 127.0.0.1:8007 (DEC-0009); UI language Vietnamese (users are coaches), code in English;
no secrets/data in the repo; `web/node_modules`, `web/dist` never committed; licenses recorded (§9).

**Risks:** pnpm 11 blocks dependency build scripts by default (may need `onlyBuiltDependencies` for native tools);
version-age constraint may make some ranges unresolvable (→ adjust range, record).
