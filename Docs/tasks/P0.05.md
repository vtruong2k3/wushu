**Interfaces:**

```text
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check.ps1 [-NoGpu] [-SkipWeb] [-DryRun] [-Root <dir>]

  -NoGpu    pytest -m "not gpu" (machines without CUDA/models). Allowed for the DoD on such machines.
  -SkipWeb  skip the four web steps; verdict "PARTIAL" (exit 0) — NOT a valid DoD run.
  -DryRun   print the step plan (machine-readable), run nothing, exit 0. Used by the tests.
  -Root     taiji_ai directory; default = parent of the script folder. Test seam only.

exit 0  every executed step passed (PASS, or PARTIAL with -SkipWeb)
exit 1  at least one step failed (all steps still executed)
exit 2  preflight/usage error: environment missing, nothing was run (or recursive invocation)
```

`-ExecutionPolicy Bypass` applies to that one process only; it is documented because a machine with the Windows
default policy `Restricted` cannot run any `.ps1` (this machine: CurrentUser = RemoteSigned, which also works).

`-DryRun` output format (stdout, one line per step, parsed by the tests):

```text
STEP|<n>|<name>|<dir relative to taiji_ai>|<command line>
SKIP|<n>|<name>|<reason>
```

`tools/repo_hygiene.py`:

```text
.venv\Scripts\python.exe tools\repo_hygiene.py [--repo-root DIR] [--max-mb 5]
  lists files with `git -C <root> ls-files -z --cached --others --exclude-standard`
  prints "<repo-relative path>: <rule>" per violation, then a count
  exit 0 clean, 1 violations, 2 git error (not a repo, git missing, undecodable output)
     or (2026-11-15, BUG-0009) a listed file that cannot be stat'ed (prints "Error: cannot stat <path>: <reason>")
```

## 2. Plan

### 2.1 Design — `tools/check.ps1`

**Layout of the script** (ASCII, CRLF via `.gitattributes`, comment-based help at the top):

```powershell
<#
.SYNOPSIS
  One-command quality gate for taiji_ai (task P0.05, AGENTS.md section 7).
.DESCRIPTION
  Runs lint, format, type, lock, test, web and repository-hygiene checks. Keeps going after a failure and
  prints a summary. Exit: 0 pass, 1 a check failed, 2 environment/usage error (nothing run).
.EXAMPLE
  powershell -NoProfile -ExecutionPolicy Bypass -File tools\check.ps1 -NoGpu
#>
[CmdletBinding()]
param(
    [switch]$NoGpu,
    [switch]$SkipWeb,
    [switch]$DryRun,
    [string]$Root = ''
)
Set-StrictMode -Version Latest
$ErrorActionPreference = 'Stop'
```

**Functions:**

| Function                                                         | Responsibility                                                                                                                                                                                                 |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Resolve-TaijiRoot([string]$Root) -> string`                     | default `Split-Path -Parent $PSScriptRoot`; must contain `pyproject.toml` and `tools\check.ps1`, else preflight error                                                                                          |
| `New-Step($Name, $Dir, $Exe, [string[]]$Arguments, $SkipReason)` | returns `[pscustomobject]` describing one step (`Dir` relative to root)                                                                                                                                        |
| `Get-Steps($Ctx) -> object[]`                                    | builds the ordered step list from the flags (single source for both `-DryRun` and the real run)                                                                                                                |
| `Write-StepPlan($Steps)`                                         | `-DryRun` output in the `STEP` / `SKIP` line format shown in §1                                                                                                                                                |
| `Test-Preflight($Ctx) -> string[]`                               | returns a list of actionable error messages (empty = OK); never runs a check                                                                                                                                   |
| `Invoke-Step($Step, $Ctx) -> object`                             | `Push-Location`; `$global:LASTEXITCODE = 0`; `& $exe @args` with output streamed to the console; result `PASS`/`FAIL` + seconds; `CommandNotFoundException` → `FAIL` with message; `Pop-Location` in `finally` |
| `Write-Summary($Results, $Ctx, $TotalSeconds)`                   | table name / result / seconds, verdict line `RESULT: <PASS, PARTIAL or FAIL> (k/n) in t s`, flags used                                                                                                         |

**Step table (order = execution order; cheap and "environment is consistent" checks first):**

| n   | Name            | Dir   | Command                                                                      | Skipped when |
| --- | --------------- | ----- | ---------------------------------------------------------------------------- | ------------ |
| 1   | `uv-lock`       | `.`   | `py -3.12 -m uv lock --check` (fallback `uv lock --check` if `py` is absent) | —            |
| 2   | `ruff-check`    | `.`   | `.venv\Scripts\python.exe -m ruff check src tests tools`                     | —            |
| 3   | `ruff-format`   | `.`   | `.venv\Scripts\python.exe -m ruff format --check src tests tools`            | —            |
| 4   | `mypy`          | `.`   | `.venv\Scripts\python.exe -m mypy src`                                       | —            |
| 5   | `pytest`        | `.`   | `.venv\Scripts\python.exe -m pytest -rs` (+ `-m "not gpu"` with `-NoGpu`)    | —            |
| 6   | `web-lint`      | `web` | `pnpm.cmd lint`                                                              | `-SkipWeb`   |
| 7   | `web-typecheck` | `web` | `pnpm.cmd typecheck`                                                         | `-SkipWeb`   |
| 8   | `web-test`      | `web` | `pnpm.cmd test`                                                              | `-SkipWeb`   |
| 9   | `web-build`     | `web` | `pnpm.cmd build`                                                             | `-SkipWeb`   |
| 10  | `repo-hygiene`  | `.`   | `.venv\Scripts\python.exe tools\repo_hygiene.py`                             | —            |

`pytest` covers every test directory under `testpaths = ["tests"]` (unit, contract, golden, api, integration when it
exists); `dataset`-marked tests keep skipping when the dataset is absent (AGENTS.md §9.4.7).

**Preflight (all checked before anything runs; every message names the fix):**

| Check                                             | Message on failure                                                      |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| root has `pyproject.toml`                         | `taiji_ai root not found at <-Root value>`                              |
| `.venv\Scripts\python.exe` exists                 | `Python env missing: run 'py -3.12 -m uv sync' in taiji_ai`             |
| `py -3.12 -m uv --version` works, or `uv` on PATH | `uv not found: py -3.12 -m pip install --user uv`                       |
| `git` on PATH and root is inside a git work tree  | `git not found / not a git repository`                                  |
| unless `-SkipWeb`: `pnpm.cmd` resolvable          | `pnpm not found (Node >= 24 + pnpm); or use -SkipWeb for a partial run` |
| unless `-SkipWeb`: `node --version` >= 24         | `Node <v> found, >= 24 required`                                        |
| unless `-SkipWeb`: `web\node_modules` exists      | `web deps missing: cd web; pnpm install --frozen-lockfile`              |

**Control flow:**

```text
parse params → resolve root → build steps
  -DryRun          → print plan → exit 0         (no preflight, no env guard: pure and fast for tests)
TAIJI_CHECK_RUNNING set → "nested gate run refused" → exit 2   (2026-11-15, BUG-0010: before preflight, needs no environment)
preflight errors   → print all → exit 2
set TAIJI_CHECK_RUNNING=1 → header (versions, flags, git short HEAD) → run every step (continue on failure)
finally: remove TAIJI_CHECK_RUNNING, restore location
summary → exit 0 (PASS / PARTIAL) or 1 (FAIL)
```

**Header** prints: PowerShell version, Python version from the venv, uv, Node, pnpm, git short HEAD + "dirty" flag,
flags. It prints no absolute paths.

**Side effects (documented in the script help):** rebuilds `web/dist`; updates tool caches (`.pytest_cache`,
`.ruff_cache`, `.mypy_cache`, `*.tsbuildinfo`) — all git-ignored. No tracked file is modified (verified V-14).

### 2.2 Design — `tools/repo_hygiene.py`

```python
"""Repository hygiene gate (AGENTS.md 5.9, 8, 9.4.8): fail if git would track data, media, model weights,
dataset or third-party clone contents, secrets, or oversized files. Used by tools/check.ps1 (task P0.05)."""

DEFAULT_MAX_MB: float = 5.0

@dataclass(frozen=True)
class Violation:
    path: str     # repo-relative, forward slashes
    rule: str     # rule id + short reason, e.g. "R1 media file (.webm)"

def classify(path: str, size_bytes: int | None, max_bytes: int) -> list[str]: ...
def find_violations(entries: Iterable[tuple[str, int | None]], max_bytes: int) -> list[Violation]: ...
def list_candidate_files(repo_root: Path) -> list[str]:
    """git ls-files -z --cached --others --exclude-standard (tracked + untracked-not-ignored)."""
def main(argv: Sequence[str] | None = None) -> int: ...
```

**Rules** (case-insensitive; path relative to the repo root, `/` separators):

| Rule                          | Matches                                                                                  | Allowed exceptions                                                                    |
| ----------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| R1 media                      | `.mp4 .mov .avi .mkv .m4v .webm .wav .mp3 .flac .m4a .aac`                               | —                                                                                     |
| R2 model weights              | `.onnx .pt .pth .ckpt .safetensors .engine .trt`                                         | —                                                                                     |
| R3 archives                   | `.zip .rar .7z .tar .gz .tgz .bz2 .xz`                                                   | —                                                                                     |
| R4 arrays / pickles           | `.npz .npy .parquet .h5 .hdf5 .feather .pkl .pickle`                                     | —                                                                                     |
| R5 databases                  | `.sqlite .sqlite3 .db` and `-wal/-shm/-journal` companions                               | —                                                                                     |
| R6 dataset contents           | anything under `datasets/`                                                               | `datasets/<area>/README.md`                                                           |
| R7 third-party clones         | anything under `repos/`                                                                  | `repos/<area>/REPOS.md`                                                               |
| R8 vendored / build output    | `node_modules/`, `.venv/`, `__pycache__/`, `taiji_ai/web/dist/` at any depth             | —                                                                                     |
| R9 runtime data / models dirs | `taiji_ai/data/**`, `taiji_ai/models/**`                                                 | `taiji_ai/data/.gitkeep`, `taiji_ai/models/.gitkeep`, `taiji_ai/models/registry.json` |
| R10 secrets                   | `.env`, `.env.*`, `*.pem`, `*.key`, `*.pfx`, `*.p12`, `id_rsa`, `id_ed25519`             | `.env.example`                                                                        |
| R11 size                      | existing file > `--max-mb` (default 5 MB; largest tracked file today `uv.lock` ≈ 100 KB) | —                                                                                     |

Deleted-but-still-indexed files have `size_bytes=None`: path rules apply, size rule does not. Git output is decoded
as strict UTF-8 (`-z`, no quoting); a decode error is exit 2 with a message, never a silent skip. Output paths are
repo-relative only.
