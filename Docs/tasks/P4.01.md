## 1. Analysis

**Goal:** the first step of the quality layer (W6): turn the target's raw keypoints into the **mask layer** — a keypoint
whose score is under `tau_kp` is NaN with the reason `low_conf`, and a frame in which fewer than half of the essential
joints are usable is `frame_invalid` as a whole. Nothing is filled, interpolated, smoothed or corrected; the raw layer
is never changed (AGENTS.md sections 5.1 and 5.3). Every excluded value carries a **reason**, because P4.07 reports
the coverage by reason and P4.02 must know what kind of hole it is looking at.

**In scope:**

- `taiji_ai/src/taiji_ai/quality/mask.py`: `MaskParams`, `MaskResult`, `apply_mask` (arrays) and `mask_track` (a thin
  wrapper that takes a `TargetTrack` of P3.06 and keeps its timeline); reason codes and their names.
- `QualityError` in `quality/__init__.py` (the error of the whole package, used by P4.02 to P4.07 too).
- Tests T-QLT-01 and T-QLT-02, on constructed arrays, on SYN-06 (`gap_mode="low_score"`, made for this task) and on a
  `TargetTrack` from the scenes of `tests/helpers/track_build.py`; a mutation check.
- A look at the real footage (M-QLT-01): the mask applied to the target tracks of the D20 pass of P3.08 (files that
  already exist), to see that the defaults do not blank everything or nothing. Counts only, nothing committed.
- Records: W6 note in `TECH_WORKFLOW_V1.md`, test rows of the plan, README status, DEC-0040, CHANGELOG, TASK_STATUS.

**Out of scope:** interpolation (P4.02), Hampel and Butterworth (P4.03, P4.05), VFR resampling (P4.04), the left/right
swap flag (P4.06), `quality.json` and the coverage numbers (P4.07), the UMONS test (P4.08), a **file format** for the
mask layer (Q1), a change of `tau_kp` or of the essential joints (they come from W6 and are only *evaluated* by P3.08;
a change would be a decision with the maintainer), any use of the mask inside the tracker (the tracker keeps its own
`min_score`, P3.02).

**Inputs / outputs / interfaces:**

| | |
|---|---|
| Input (array level) | `keypoints` `(T, 26, 2)` float, image pixels of the upright image, x to the right, y down; `scores` `(T, 26)` float, the model's own scores (not range-checked upstream: a score may be NaN, below 0 or above 1); `tracked` `(T,)` bool or `None` (= every frame is a frame of the target); `params`. Floating dtype only (an integer array cannot hold NaN). |
| Input (track level) | `TargetTrack` (`keypoints`, `scores` NaN where `status != TRACKED`, `status`, `t_sec`, `frame_index`, `in_segment`). |
| Output | `MaskResult`: `keypoints` `(T, 26, 2)` same dtype as the input, NaN where `reason != ok`; `scores` as given; `reason` `(T, 26)` uint8; `tracked` `(T,)`; `n_essential_valid` `(T,)` int; `frame_invalid` `(T,)` bool; `params`; property `usable = tracked & ~frame_invalid`. `MaskedTrack` (track level): the `MaskResult` plus `frame_index`, `t_sec`, `in_segment`, `status` of the track, so that the next steps do not need the track again. New arrays; the inputs are not changed. |
| Units | pixels (positions), seconds (`t_sec`, only carried), scores unitless |

**Reason codes** (`uint8`, names in `REASON_NAMES`, same style as `STATUS_NAMES` of P3.06): `0 ok`, `1 low_conf`
(finite score under `tau_kp`), `2 non_finite` (a coordinate or the score is NaN or infinite: there is no observation),
`3 not_tracked` (the frame is not a frame of the target: `lost`, `target_lost` or `before_target`; which of the three
stays in `MaskedTrack.status`), `4 frame_invalid` (the joint passed its own rules but its frame has too few essential
joints). A joint gets the **first** reason that applies, in the order `not_tracked`, `non_finite`, `low_conf`,
`frame_invalid`, so that a frame that is invalid because six essential joints were `low_conf` keeps the more specific
reason on those six and `frame_invalid` only on the joints that would otherwise have been kept.

**The two rules (from W6, decided before this task):**

1. `tau_kp = 0.3`: a score **under** `tau_kp` is excluded; a score **equal** to it is kept (the same comparison as
   `valid_keypoint_mask`, which is also what the tracker and the audit use: one definition of "valid", reused, not
   re-written).
2. Essential joints `ESSENTIAL = (5, 6, 11, 12, 13, 14, 15, 16, 24, 25)` of `pose/skeleton.py` (shoulders, hips,
   knees, ankles, heels; W6 names them "vai, hông, gối, mắt cá, gót"): a **tracked** frame with fewer than
   `min_essential_fraction = 0.5` of them usable is `frame_invalid`. W6 says "less than 50 % valid" and T-QLT-02 says
   "missing more than 50 %": both mean that **5 of 10 is still a valid frame and 4 of 10 is not** (the test fixes the
   boundary). `frame_invalid` blanks **all 26 joints** of the frame (W6: "cả frame"). Frames that are not tracked are
   not `frame_invalid`: they are absent (`not_tracked`).

## 2. Plan

**Design:**

```python
TAU_KP: Final = 0.3                      # W6; evaluated by P3.08, not tuned
MIN_ESSENTIAL_FRACTION: Final = 0.5      # W6
OK, LOW_CONF, NON_FINITE, NOT_TRACKED, FRAME_INVALID = 0, 1, 2, 3, 4
REASON_NAMES: Final = ("ok", "low_conf", "non_finite", "not_tracked", "frame_invalid")

@dataclass(frozen=True)
class MaskParams:                        # validated in __post_init__ (QualityError)
    tau_kp: float = TAU_KP               # finite, in [0, 1]
    essential: tuple[int, ...] = ESSENTIAL   # non-empty, unique, each in 0..25
    min_essential_fraction: float = MIN_ESSENTIAL_FRACTION   # in (0, 1]

@dataclass(frozen=True, eq=False)
class MaskResult: keypoints, scores, reason, tracked, n_essential_valid, frame_invalid, params  # + usable

@dataclass(frozen=True, eq=False)
class MaskedTrack: mask: MaskResult; frame_index; t_sec; in_segment; status

def apply_mask(keypoints, scores, tracked=None, params=None) -> MaskResult
def mask_track(track: TargetTrack, params=None) -> MaskedTrack
```

Algorithm (vectorised, `O(T x 26)`, no loop over frames):

1. Validate: floating dtypes, `keypoints (T, 26, 2)`, `scores (T, 26)` with the same `T`, `tracked (T,)` bool (strict:
   an integer array is refused), `T = 0` allowed (empty result).
2. `finite = isfinite(keypoints).all(-1) & isfinite(scores)`; `confident = finite & (scores >= tau)` (the same
   expression as `valid_keypoint_mask`, which is **called**, not copied).
3. Reason per joint: `not_tracked` where the frame is not tracked; else `non_finite` where not finite; else `low_conf`
   where finite and under `tau`; else `ok`.
4. `n_essential_valid = confident[:, essential].sum(-1)` for tracked frames (0 for the others);
   `frame_invalid = tracked & (n_essential_valid < min_essential_fraction * len(essential))` (a float comparison with
   no rounding: 4 < 5.0 is invalid, 5 < 5.0 is not).
5. Joints still `ok` in a `frame_invalid` frame get `frame_invalid`.
6. Copy the keypoints, set NaN where `reason != ok`; `scores` copied as given (they are the model's confidence, not an
   observation; NaN stays NaN); arrays are marked read-only (the layer is not edited in place by later stages).

`mask_track` calls `apply_mask(track.keypoints, track.scores, track.status == TRACKED, params)` and keeps
`frame_index`, `t_sec`, `in_segment`, `status` unchanged (the margins of 1 s stay: P4.03 and P4.05 need them at the
edges of the segment; cutting to the segment is the job of the metric stage, which has `in_segment`).
