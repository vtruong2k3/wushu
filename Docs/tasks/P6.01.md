### 1.2 Goal

The per-frame feature vector of Appendix C.1 for the comparison of a segment with a reference segment (W8): the positions
of the chosen joints relative to the middle of the hips, divided by the segment's trunk scale `Λ`, and the `sin` and `cos`
of the angles of the limb segments and of the trunk axis, with a mask that says, for every frame and every joint or
segment, whether the feature is a value and why not. P6.02 (masked cost matrix: `min_visible`, joint weights) and P6.03
(constrained DTW) read it; P6.04 (local tempo) needs its real clock.

### 1.3 Facts read (2026-11-17)

### 1.5 Interface (proposed)

```python
# compare/__init__.py
class CompareError(Exception): ...

# compare/features.py
FEATURE_VERSION = "1"
DEFAULT_JOINTS = ("LShoulder", "RShoulder", "LElbow", "RElbow", "LWrist", "RWrist",
                  "LHip", "RHip", "LKnee", "RKnee", "LAnkle", "RAnkle")          # 12 (Q2)
SEGMENTS = {  # name: (proximal, distal); "trunk" is mid-hip -> mid-shoulder
    "l_upper_arm": (LShoulder, LElbow), "l_forearm": (LElbow, LWrist),
    "r_upper_arm": (RShoulder, RElbow), "r_forearm": (RElbow, RWrist),
    "l_thigh": (LHip, LKnee), "l_shank": (LKnee, LAnkle),
    "r_thigh": (RHip, RKnee), "r_shank": (RKnee, RAnkle),
    "trunk": (mid-hip, mid-shoulder),
}
DEFAULT_SEGMENTS = tuple(SEGMENTS)                                                # 9 (Q3)

@dataclass(frozen=True, eq=False)
class FeatureUnit:  kind: Literal["position", "angle"]; name: str; joints: tuple[int, ...]

@dataclass(frozen=True, eq=False)
class FrameFeatures:
    t_sec: np.ndarray        # (N,) float64, seconds from the stream start (the grid rows of the segment)
    values: np.ndarray       # (N, U, 2) float64: a position in trunk lengths (x right, y down, from the mid-hip),
                             #   or (sin φ, cos φ); NaN where not valid, never 0
    valid: np.ndarray        # (N, U) bool
    reason: np.ndarray       # (N, U) uint8: 0 valid, 1..6 the quality reason of the first unusable joint of the unit,
                             #   19 scale_unavailable (positions only), 23 zero_length (a segment whose ends coincide)
    bridged: np.ndarray      # (N, U) bool: a valid feature that leans on a bridged (interpolated) cell
    units: tuple[FeatureUnit, ...]   # positions first, then angles, in the order asked
    scale_px: float          # Λ, NaN when unavailable
    scale_rows: int; scale_s: float
    roll_deg: float; step_s: float | None
    recording_id: str; data_sources: tuple[DataSource, ...]; version: str

def frame_features(layer: PoseFiltered, *, roll_deg: float = 0.0,
                   joints: Sequence[str] = DEFAULT_JOINTS, segments: Sequence[str] = DEFAULT_SEGMENTS,
                   min_scale_s: float | None = None) -> FrameFeatures
```

Formulas, in float64 on the roll-corrected positions `p' = correct_roll(p, roll_deg)`:

- position unit `j`: `(p'_j(t) − H'(t)) / Λ` where `H' = (p'_11 + p'_12) / 2` and `Λ = scale_of(segment rows,
  min_scale_s).scale_px` (the median trunk length of the segment, which a roll does not change);
- angle unit `s` from `a` to `b`: `φ = atan2(x'_b − x'_a, −(y'_b − y'_a))` (0 is up, positive toward the image right: the
  convention of B2, so the trunk unit is `θ` of trunk lean), value `(sin φ, cos φ)`; computed from the vector directly
  (`dx / |v|`, `−dy / |v|`), so no angle is wrapped and 359° and 1° are neighbours.

### 1.6 Conventions fixed by this task

1. **Validity of a unit:** a position needs its joint, both hips and `Λ`; an angle needs its two ends (for the trunk the four
   joints 11, 12, 5, 6) and a length above 0, **not** `Λ` (an angle has no scale). A bridged cell counts as a value and is
   flagged (as in the metrics).
2. **Reason of an invalid unit,** in this order: the reason of the first unusable joint of the unit (the joint itself, then
   the hips; for an angle its ends in order), then 19 `scale_unavailable` for a position, then 23 `zero_length` for an angle.
   The codes 1 to 6 and 19 have the numbers of `MissingReason`; 23 is new and belongs to the features only (`FeatureReason`).
3. **No fabricated value:** an invalid unit is NaN in both components; the arrays are new and read-only; the layer is never
   changed.
4. **One `Λ` per segment** (W8): scaling one frame changes only that frame's features (and `Λ` only through the median).

## 2. Plan

### 2.1 Design

`frame_features` cuts the segment rows (`segment_rows`), takes `Λ` (`scale_of`), corrects the roll of every joint it needs,
and computes the units in one vectorised pass. Each unit's validity and reason come from `geometry.unusable_reason` on its
joints (so the order of the reasons is the one of the metrics), then the scale or the length; `bridged` from
`geometry.bridged`. Nothing is stored: the result is a frozen dataclass of read-only arrays.

Checked against the code of 2026-11-17: `segment_rows` and `scale_of` (`metrics/rows.py`), `mid_hip`, `mid_shoulder`,
`midpoint`, `unusable_reason`, `bridged`, `correct_roll`, `MAX_ROLL_DEG` (`metrics/geometry.py`), `IDX` (`pose/skeleton.py`),
`PoseFiltered` (`quality/layers_io.py`), `DataSource` (`schemas/quality_layers.py`), `CompareError` (`compare/__init__.py`,
written by the coordinator, DEC-0064: this task does not edit it), the helpers of `tests/helpers/metric_layers.py` and
`make_pair` / `make_sequence` of `tests/helpers/synth.py`.

1. `unusable_reason` and `bridged` refuse a repeated joint (`geometry._joints`). A position unit of a hip would be
   `(j, 11, 12)` with `j` repeated, so the joint list of a unit is `(j, 11, 12)` with duplicates removed, order kept:
   `LHip -> (11, 12)`, `RHip -> (12, 11)`; the first unusable joint of the list gives the reason (§1.6 item 2).
2. `SEGMENTS` is `name -> (proximal joints, distal joints)`, each end being the tuple of joints whose mean is the end
   point (`((5,), (7,))` for the left upper arm; `((11, 12), (5, 6))` for the trunk: the mid-hip and the mid-shoulder of
   Appendix B). The `joints` of an angle unit are proximal then distal: `(5, 7)` and `(11, 12, 5, 6)`, the order in
   which the reason of the first unusable joint is taken (the hips before the shoulders, as `trunk_lean`).
3. The helpers of `metrics/` raise `MetricError`; this module raises `CompareError`, so a `MetricError` raised while the
   layer is read (a cell with one NaN coordinate, a reason that does not fit the cell) is re-raised as `CompareError`
   with `raise ... from`, never swallowed. Messages name the argument and echo a number or a type, never a string given
   by the caller (an unknown joint name is reported by its position in the list).
4. `roll_deg` is validated as a finite number first (so the message cannot echo a string) and then through
   `geometry.correct_roll`, which owns the 45 degree limit and its tolerance; the keypoints are corrected once, all 26
   joints, and the mid-hip and the mid-shoulder of the corrected points are the means of the corrected joints
   (`correct_roll` is linear, so this equals the corrected mean).
5. `Λ` is taken on the **uncorrected** rows (a rotation does not change a length) and `scale_of(...).scale_px` is NaN
   both when no row has a trunk and when the valid rows last less than `min_scale_s`; `scale_rows` and `scale_s` are
   kept in both cases so that a report can say why.

### 3.1 Extension of the plan for R1 (2026-11-17, at the coordinator's request, after the first report of this task)

The first report found R1 (§7): a segment shorter than the noise of the pose is a valid feature with an arbitrary
direction. The coordinator asked for it to be fixed **inside P6.01** with one additive, optional argument. Plan re-read:
2026-11-17 — OK against the module and the tests as they stand (130 tests, 83 mutants); the extension changes no
default, no field and no unit order of the contract of `P6_overview.md` §3.1.

- **Signature:** `frame_features(..., min_segment_length: float | None = None)`. `None` applies none, as `min_scale_s`;
  the value belongs to the caller and later to a signed record (AGENTS.md 5.5). A number is finite and above 0, in
  **trunk lengths** (the length of the segment in pixels divided by `Λ`); a bool, a string, NaN, infinity, 0 and a
  negative number are `CompareError` naming `min_segment_length` (a number or a type is echoed, never a string).
- **Effect, on angle units only** (positions are not touched), after the test of the exact zero: a row whose length is
  exactly 0 keeps 23 `zero_length` and the new reasons never replace it; if a minimum is given and `Λ` is not finite,
  every angle row that would otherwise be valid is 19 `scale_unavailable` (the minimum is in trunk lengths, so it needs
  `Λ`; without a minimum an angle still needs none); otherwise a row whose `length / Λ` is **below** the minimum is
  invalid with the new `FeatureReason.short_segment = 24`. A length exactly equal to the minimum is valid ("at least").
  Invalid means NaN in both components and `valid` False. The order of the reasons of an angle is now: a missing joint
  (1 to 6), 23, then 19 or 24.
- **Compatibility:** `min_segment_length=None` must give arrays identical to a run without the argument (a test).
- **Length** is `hypot(dx, dy)` of the roll-corrected ends, the same `dx`, `dy` as the direction (a rotation does not
  change it); the trunk is compared like any other segment (its length over `Λ` is about 1 when the pose is steady).
- **Tests (T-CMP-01i, new):** the boundary below, equal and above per segment and per row on layers whose lengths and
  `Λ` are exact in float (so `length / Λ` is exactly the number written); a wavy body for the mixtures, with the
  independent reference extended to the same rule and to the reasons (`compare_features_ref.expected_reasons` and
  `length_ratios`, by plain loops); `Λ` not finite with and without the minimum; the order of the reasons; the flag of a
  bridge only on valid rows; positions untouched; refusals. Red first, then the golden re-measurement on SYN-10 at 1 px
  (`scale_px` 120) with `min_segment_length=0.05` (a value chosen only for the test), then the mutants of the new code.

### (d) Text for a `DEC-NNNN`

**DEC-NNNN — Frame features of the comparison: one axis of units, trunk-length positions and (sin, cos) angles, their own reason set, an optional minimum segment length (P6.01, 2026-11-17).**
Decision: the features of a segment are one array `values (N, U, 2)` whose units are the positions of the chosen joints
(in trunk lengths from the mid-hip, divided by one median trunk length per segment) and then the directions of the chosen
segments as `(sin φ, cos φ)` with `φ = atan2(dx, -dy)`; each unit has `valid`, a `reason` and a `bridged` flag; the
camera roll is taken out of every joint first. The default sets are 12 joints and 9 segments (shoulders, elbows, wrists,
hips, knees, ankles; both upper arms, forearms, thighs, shanks, and the trunk axis). The reasons are `FeatureReason`: the
numbers of `MissingReason` for 1 to 6 and 19, and two new codes that belong to the features only, 23 `zero_length` and
24 `short_segment` (a code in `MissingReason` would change the schema of the metric series, which never produces them). A
unit is a value when every joint it needs is a value (a position: its joint, both hips, `Λ`; an angle: its ends, a length
above 0 and, if asked, at least `min_segment_length`); the reason is that of the first unusable joint in the order the
joint itself then the hips, then 19 for a position without `Λ`, for an angle 23, then (only with the minimum) 19 without
`Λ` or 24 below the minimum. `min_segment_length` is optional, in trunk lengths, has no default (`None`: none applied;
the value is the caller's and later a signed record's, AGENTS.md 5.5), applies to angles only, and a length equal to it
is enough. The result echoes `min_scale_s` and `min_segment_length`.
Reasons: the masked mean of Appendix C.2 needs one mask per joint or segment, each with its own 2-vector, so one axis is
the shape P6.02 reads; a unit vector has no wrap; one `Λ` per segment is W8; the trunk unit equals the `θ` of B2 so the
two conventions cannot drift apart; the direction of a segment as short as the noise of the pose is arbitrary (SYN-10 at
1 px of noise: the diagonal of a same-shape pair used 65 to 112 % of `shape_distance_max`, 42 to 71 % after a cut at
0.05 trunk lengths), so the caller needs a way to mask it without the module inventing a threshold.
Alternatives rejected: separate arrays for positions and angles (two masks and two loops in P6.02); the angle in radians
or degrees (a wrap at 180); `Λ` per frame (W8 forbids it); a default minimum length (a threshold without a record); a
minimum in pixels (not invariant to scale); the minimum in `MissingReason` (schema change); weights only (they do not
remove a direction, they dilute it); mirroring a left movement onto a right one and velocity features (not in
Appendix C, coach-requested later).
Consequence: the value of `min_segment_length` is chosen by P6.02's analysis and then by the pilot (the coach); the `D`
tests on SYN-10 must be measured with noise; P6.03b's settings fingerprint includes the two minimums.

```text
frame_features(layer: PoseFiltered, *, roll_deg: float = 0.0,
               joints: Sequence[str] = DEFAULT_JOINTS, segments: Sequence[str] = DEFAULT_SEGMENTS,
               min_scale_s: float | None = None, min_segment_length: float | None = None) -> FrameFeatures

FrameFeatures (frozen dataclass of new read-only arrays):
  t_sec (N,) float64 | values (N, U, 2) float64 (NaN in both components where not valid, never 0)
  valid (N, U) bool | reason (N, U) uint8 (FeatureReason) | bridged (N, U) bool (only on a valid unit)

  min_scale_s: float | None = None | min_segment_length: float | None = None   (echoes; trailing, with a default)

FeatureReason: 0 valid | 1 to 6 and 19 the numbers of MissingReason | 23 zero_length | 24 short_segment
Order of the reason of a unit: (1) the layer's reason (1 to 6) of the first joint it needs without a value
  (position: its joint, then the hips, a hip not repeated; angle: its ends in order, the trunk hips then shoulders);
  (2) position: 19 scale_unavailable when Λ is not finite;
  (3) angle: 23 zero_length when the two ends coincide exactly; then, only if min_segment_length is given,
      19 scale_unavailable when Λ is not finite, else 24 short_segment when length / Λ < min_segment_length
      (a length equal to it is valid). Without min_segment_length an angle needs no Λ.
min_segment_length: trunk lengths (length in px / Λ), finite and above 0 or None (none applied), no default value,
  angles only. P6.02 must read `valid` (False = masked, whatever the reason); two feature sets that are compared
  must have the same units, version and settings (the echoes make that checkable).
```
