## 1. Analysis

### 1.1 Goal

A distance `D` means nothing alone: a coach's own takes of a movement differ from each other too. With two or more
reference takes of the same movement, the distances between them are the "normal band" (W8, Appendix C.5); a trainee's
distance to those references is then shown against it: below, inside or above the band, and how far, **never as a score
from 0 to 100**.

### 1.2 Facts read (2026-11-17)

- Plan row P6.06: "normal band from several reference takes; report the trainee's position against it", output
  `compare/reference_band.py`, test T-CMP-08 ("a band from two references or more; one reference says 'not enough'").
- Appendix C.5: the band is the distribution of `D` between the coach's reference takes; show the trainee's `D` against it;
  no conversion to a 0–100 score. W8: use two reference takes or more.
- A distance is comparable with another only when both were made with the same settings (features, weights,
  `min_visible`, band, step pattern): P6.03b's `Alignment.settings` holds them.
- AGENTS.md 5.5: no threshold here; the band is a description, not a verdict.

### 1.3 Scope

**In:** `compare/reference_band.py`: `Comparison`, `ReferenceBand`, `reference_band(between_references, trainee)`; tests
T-CMP-08a..h; mutation check; docs. **Out:** running the alignments (the caller does, with P6.03b), choosing the reference
takes (the coach, P8.06), any label such as "good" or "bad" (a record's, later).

### 1.4 Interface

```python
@dataclass(frozen=True)
class Comparison:
    reference_id: str; query_id: str        # short IDs of segments (pseudonymous), never names or paths
    distance: float | None                  # D of the alignment; None: no path
    settings: Mapping[str, object]          # Alignment.settings (must be equal across a band)

@dataclass(frozen=True)
class ReferenceBand:
    status: Literal["ok", "insufficient_references", "no_trainee_distance"]
    references: tuple[str, ...]; n_pairs: int; n_pairs_without_path: int
    band_low: float | None; band_median: float | None; band_high: float | None      # of the pairs' distances
    trainee_distances: tuple[float | None, ...]                                     # one per reference, in order
    trainee_value: float | None                                                     # the median of the finite ones
    position: Literal["below", "within", "above"] | None
    ratio_to_high: float | None                                                     # trainee_value / band_high

def reference_band(between_references: Sequence[Comparison], trainee: Sequence[Comparison]) -> ReferenceBand
```

Rules: the references are the IDs of `between_references`; each unordered pair appears once and **every pair** of the
references is there; the trainee is compared with **every** reference, once; every `settings` is equal; a distance of a
pair or of the trainee that is `None` (no path) is left out and counted; fewer than two references or no finite pair gives
`insufficient_references`; no finite trainee distance gives `no_trainee_distance`; `ratio_to_high` is `None` when
`band_high` is 0 (identical references).

### 1.5 Questions for the maintainer

| #  | Question | Default if no answer |
| -- | -------- | -------------------- |
| Q1 | The band | **From the smallest to the largest distance between the references** (with the median): with two to five takes a percentile would be invented precision; the number of references is reported |
| Q2 | The trainee's value | **The median of its distances to the references** (like with like: each is a distance between two takes, as the band's are). Alternative: the smallest (the nearest reference) |

## 3. Plan re-read (before coding)

Plan re-read: 2026-11-17 — OK. Read the whole file against the current tree: `compare/__init__.py` holds `CompareError`;
`compare/dtw.py` is done (`DtwResult.distance` is `D`, the plain mean of the cost over the listed cells, `normalised` is
not `D`; `params` echoes `band`, `step`, `n`, `m`); `compare/align.py` (P6.03b, `Alignment.settings`) does not exist yet, so
this module works on plain values (`Comparison`) and never imports `dtw.py`. The contract of overview §3.3 and §3.4 is not
changed (it names only that P6.06 compares `D` with `D` made with equal settings). The plan leaves some points open; they
are settled here, before coding, and none changes a name, a type or a meaning of the overview:

1. **Where the references come from.** §1.4 says "the references are the IDs of `between_references`", but a pair needs two
   references, so one reference (T-CMP-08b: "one reference says 'not enough'") has no pair and could not be given at all.
   The references are the IDs found in the pairs **and** the `reference_id` of the trainee's comparisons, in sorted order
   (so the result does not depend on the order or the direction of the caller's list). One reference is then
   `between_references=[]` with the trainee compared with it; no reference at all is two empty lists. A trainee compared
   with a reference that no pair mentions is refused as a missing pair (every pair of the references is needed).
2. **`n_pairs`** is the number of pairs given, `k (k - 1) / 2` for `k` references (with and without a path);
   `n_pairs_without_path` of them have `distance=None`; the band is made of the other ones.
3. **Order of the statuses:** `insufficient_references` (no finite pair: fewer than two references have no pair at all)
   first, then `no_trainee_distance`, then `ok`. With `insufficient_references` the band fields, the position and the
   ratio are `None`; `trainee_distances` and `trainee_value` still echo what the trainee's comparisons say (an observation,
   not a result of the band). With `no_trainee_distance` the band is reported.
4. **What is refused beyond the plan's list** (each serves AC2, "distances made with other settings are never mixed", or
   the rule that a message never echoes free text): an empty `settings` (it would make the equality check blind); a
   `settings` name that is not a short code (the names of the differing settings are written in the message); a
   `distance` that is not `None` or a finite number of at least 0 (`D` is a mean of non-negative costs; a boolean, NaN or
   infinity is a defect upstream); a `Comparison` of a segment with itself; trainee comparisons with more than one
   `query_id` (the trainee is one segment). Values of `settings` are compared by value, extended to arrays and to
   sequences and mappings that hold arrays (a list and a tuple with equal items are equal: a JSON round trip makes
   tuples lists).
5. **Every setting that differs is named** (sorted), not only the first.

một reference không có cặp nào nên được đưa vào là `between_references=[]` cùng người tập được so với nó. **Dải** là khoảng cách nhỏ nhất, trung vị và lớn nhất giữa mọi cặp reference (với 2 đến 5 take thì percentile là độ chính xác bịa ra); **giá trị của người tập** là trung vị các khoảng cách của người tập tới các reference (cùng loại với dải: mỗi cái là khoảng cách giữa hai take). `position`: `below` khi giá trị nhỏ hơn đáy dải, `above` khi lớn hơn đỉnh, `within` còn lại, **gồm cả hai đầu**; `ratio_to_high` là giá trị chia đỉnh dải (không bị chặn ở 1 hay 100; `None` khi đỉnh bằng 0, tức các take giống hệt nhau). **Không có điểm 0–100 và không có nhãn tốt/xấu** (AGENTS.md 5.5): chỉ mô tả, nhãn cần `metric_record` đã ký. **Bắt buộc đủ và đúng:** mọi cặp của các reference đúng một lần (cặp thiếu hay lặp bị từ chối và nêu cặp, vì dải từ vài cặp sẽ phụ thuộc cặp nào đã chạy), người tập được so với mọi reference đúng một lần và là một segment, `settings` giống hệt nhau ở mọi so sánh (khác ở đâu thì từ chối và nêu tên mọi setting khác nhau; `settings` rỗng cũng bị từ chối vì nó làm phép so vô nghĩa; mảng và dãy được so theo giá trị), `distance` là `None` hoặc số hữu hạn không âm, mã là mã ngắn (đường dẫn hay tên có khoảng trắng bị từ chối và **không bao giờ lặp lại trong thông báo**; module không ghi log). **Trạng thái, theo thứ tự:** `insufficient_references` khi không cặp nào có khoảng cách hữu hạn (ít hơn hai reference thì không có cặp nào): dải, vị trí và tỉ lệ là `None`, các khoảng cách của người tập vẫn được echo (báo cáo phải đọc `status` trước khi đặt một con số cạnh một dải); ### 9.d Decision text (for `DECISIONS.md`, `DEC-NNNN`)

**P6.06 details of the normal band (`compare/reference_band.py`):** (1) the references are the segment IDs found in the pairs of `between_references` **and** the `reference_id` of the trainee's comparisons, in sorted order (the plan said "the IDs of `between_references`", which cannot hold one reference, and T-CMP-08b needs one); every pair of them must be given exactly once, in either direction, and the trainee must be compared once with each, as one segment (a trainee compared with a reference that no pair holds is refused as a missing pair); (2) `n_pairs` is the number of pairs given (`k (k - 1) / 2`), `n_pairs_without_path` of them have `distance=None`, and the band is made of the other ones; (3) the statuses are checked in the order `insufficient_references` (no finite pair), `no_trainee_distance`, `ok`; with `insufficient_references` the band, the position and the ratio are `None` and the trainee's own distances and value are still echoed; (4) beyond the plan, the call refuses: empty `settings`, a `settings` name that is not a short code, a `distance` that is not `None` or a finite number of at least 0, a comparison of a segment with itself, trainee comparisons with more than one `query_id`; every setting that differs is named, sorted; the values of `settings` are compared by value, extended to arrays and to sequences and mappings that hold arrays (a list and a tuple with equal items are equal); (5) the band is the smallest to the largest distance between the references with the median, the trainee's value is the median of its distances (Q1 and Q2 defaults), the position includes both ends, and `ratio_to_high` is not capped; there is no score and no label (Q5). **Reason:** with two to five takes a percentile would be invented precision; the trainee's median is a like-with-like number (each is a distance between two takes); an incomplete set of pairs would make the band depend on which pairs were run; an empty `settings` would make the equality check vacuous; a message names only checked short codes and never echoes a path or a name (AGENTS.md 5.9). **Who asked:** the maintainer asked on 2026-11-17 to start the parallel tasks with subagents after reading the plans, so the defaults of Q1 to Q5 apply (DEC-0064). | ACCEPTED | `Docs/tasks/P6.06.md`
