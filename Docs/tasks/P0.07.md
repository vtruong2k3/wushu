## 1. Analysis

**Goal:** a deterministic generator of synthetic HALPE_26 pose sequences **with known answers**, so that the quality
(P4), metric (P5), comparison (P6) and tracking (P3) modules can be tested against ground truth before any real data
exists. It covers the 12 scenarios SYN-01..SYN-12 of IMPLEMENTATION_PLAN §14.3 and fixes the tolerances those tests
will use ("Tolerance chốt ở P0.07").

**Plan row (IMPLEMENTATION_PLAN §4):** "Bộ sinh skeleton tổng hợp cho test (mục 14.3)"; owner A; 1 day; output
`tests/helpers/synth.py`; check T-SYN-01..03. **§14.3:** `make_sequence(...)` returns `kp (T,26,2)`, `score (T,26)`,
`t_sec (T,)` and an answer dict. **T-SYN-01..03 (§15.1):** "shape, đáp án đúng, seed cố định cho kết quả lặp lại".
**P0 acceptance (§4):** "Bộ sinh skeleton tổng hợp tạo đủ các kịch bản ở mục 14.3".

**Inputs / outputs / interfaces (conventions):**

- Image pixels, x right, **y down** (AGENTS.md §6, TECH_WORKFLOW Appendix B). `kp` float32 `(T, 26, 2)`, `score` float32
  `(T, 26)` in [0, 1], `t_sec` float64 `(T,)`, strictly increasing, starting at 0. NaN = not observed.
- Joint order = `taiji_ai.pose.skeleton.JOINTS` (`halpe26/1`); the generator imports it and never re-declares it.
- Default body **faces the camera**: the person's left side (L\* joints) appears on the **image right**
  (`x_LShoulder > x_RShoulder`). `facing="away"` mirrors that.
- Body scale: trunk length `L = ‖S − H‖` (mid-shoulder to mid-hip) = `scale_px` exactly in the neutral pose, so the
  true `Λ` of Appendix B is known.
- Angles in degrees. θ follows Appendix B2: `θ = atan2(x_S − x_H, y_H − y_S)`, positive = top leans to the image
  right. Camera roll β uses the **same** sign: a true vertical line shows the angle β in the image, so the measured
  `θ_raw = θ_body + β` and `θ_body = θ_raw − roll_cam` with `roll_cam = β`.
- Defaults: 30 fps, 1920 × 1080 image, `scale_px = 200`, body centred at x = 960 with the feet at y ≈ 900.

**Constraints that apply (AGENTS.md):**

- §5.1 "never fabricate observations": synthetic data is **test-only**. It lives under `tests/`, is never imported by
  `src/`, never written to `data/`, and every object carries `synthetic=True` and `generator_version`.
- §6.3 / §6 reproducibility: all randomness comes from `np.random.default_rng(seed)` passed down explicitly; no global
  RNG state is read or changed.
- §9.4.7: no dataset content in tests or fixtures; nothing is committed as `.npz` (repo-hygiene R4). Everything is
  generated at test time.
- §5.5 "no universal thresholds": not affected. The tolerances here are **test tolerances** for synthetic data, not
  metric thresholds for conclusions; they need no `metric_record` and no coach sign-off.
- §5.4 units documented: every truth value says its unit (px, Λ, s, °, Λ/s).

## 2. Plan

### 2.1 Design

```text
tests/helpers/synth.py
  constants   SYNTH_VERSION = "syn/1", DEFAULT_FPS, IMAGE_SIZE, SCALE_PX, TOLERANCES (§2.5)
  body        neutral_pose(scale_px, origin, facing) -> (26, 2)       body template in units of L, y down
  motion      ACTIONS = {"raise_lower": …, "open_close": …}           pose = f(phase φ ∈ [0, 1])
              phase(t) from a speed profile with exact zero-speed pauses and cosine ramps
  time        cfr_times(duration, fps), vfr_times(...)                float64, strictly increasing
  modifiers   add_noise(kp, sigma, rng), apply_gaps(...), apply_lr_swap(...), apply_roll(kp, beta, centre)
  builders    make_sequence(scenario, *, seed=0, **params) -> SynthSequence   (SYN-01..09)
              make_pair(scenario, *, seed=0, **params)     -> SynthPair       (SYN-10, SYN-11)
              make_scene(scenario, *, seed=0, **params)    -> SynthScene      (SYN-12)
  registry    SCENARIOS: dict[str, ScenarioSpec(kind, builder, params with defaults, truth keys, units)]
```

Public types (frozen dataclasses; arrays are read-only views so a test cannot corrupt a shared fixture):

```python
@dataclass(frozen=True)
class SynthSequence:
    kp: np.ndarray        # (T, 26, 2) float32, image px, y down; NaN = not observed
    score: np.ndarray     # (T, 26) float32 in [0, 1]
    t_sec: np.ndarray     # (T,) float64, strictly increasing, t_sec[0] == 0
    truth: dict[str, Any] # scenario answer; every key documented with its unit in SCENARIOS
    kp_true: np.ndarray   # (T, 26, 2) float32 noise-free, gap-free, swap-free positions (for error checks)
    scenario: str
    seed: int
    params: dict[str, Any]          # all parameters after defaults were applied
    generator_version: str = SYNTH_VERSION
    synthetic: bool = True

@dataclass(frozen=True)
class SynthPair:      # SYN-10 / SYN-11
    ref: SynthSequence
    query: SynthSequence
    truth: dict[str, Any]

@dataclass(frozen=True)
class SynthScene:     # SYN-12
    kp: np.ndarray        # (T, N, 26, 2) float32; NaN where a slot is empty
    score: np.ndarray     # (T, N, 26) float32
    bbox: np.ndarray      # (T, N, 4) float32 xyxy px; NaN where empty
    t_sec: np.ndarray
    truth: dict[str, Any] # person_id (T, N) int (−1 = empty slot), target_id, absent intervals
    ...
```

Rules for every builder:

- Unknown scenario → `ValueError` listing valid IDs; unknown keyword → `TypeError` (no silent ignore); invalid values
  (duration ≤ 0, fps ≤ 0, gap outside the clip, overlapping pauses, amplitude that pushes joints off-image) →
  `ValueError` with the parameter name.
- `seed` → one `np.random.default_rng(seed)`; sub-streams via `rng.spawn()`, one per random component, so adding a
  component does not change existing streams.
- `noise_px` (default 0) and `score_base` (default 0.9) are accepted by every scenario. Noise is applied **after**
  truth is computed; `kp_true` stays noise-free.
- Gaps: `gap_mode="low_score"` (coordinates jittered, score 0.05 < τ_kp = 0.3: exercises the mask, P4.01) or
  `"nan"` (coordinates NaN, score 0: exercises gap filling, P4.02).

Scenario details (truth keys in `code`; units in brackets):

| ID     | Construction                                                                                                                                                                            | Main truth keys                                                                                                                                             |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SYN-01 | neutral pose, no motion, i.i.d. Gaussian noise `noise_px` (default 1.0)                                                                                                                 | `hip_range` = 0 [Λ], `speed[g]` = 0 [Λ/s], `pause_intervals` = [(0, t_end)] [s], `scale_px`                                                                 |
| SYN-02 | upper body + hips move vertically `A·Λ·sin(2πft)`, feet fixed, knees halfway; trunk rigid                                                                                               | `A` [Λ], `f` [Hz], `hip_y(t)` [px], `expected_range_p95_p5` = `2A·sin(0.45π)` [Λ] (whole periods), `nominal_range` = 2A                                     |
| SYN-03 | upper body rotated about H by θ(t): constant `theta_deg` or linear `theta_from`→`theta_to`                                                                                              | `theta_deg(t)` [°], `median_theta_deg` [°]                                                                                                                  |
| SYN-04 | SYN-03 body, then the whole image rotated by β about the image centre                                                                                                                   | `roll_deg` = β, `theta_body_deg(t)`, `vertical_line` = two image points of a true vertical [px]                                                             |
| SYN-05 | action `raise_lower` driven by φ(t); speed profile 0 inside `pauses` (default 3), cosine ramps `ramp_s` (default 0.2 s)                                                                 | `pause_intervals` [s] and `pause_frames`, `n_pauses`, `speed[g](t)` true group speed (median of joint speeds, Appendix B3) [Λ/s]                            |
| SYN-06 | SYN-05 motion; joint gaps `gaps=[(joints, t0, dur)]` (default one 100 ms and one 300 ms gap on the hands)                                                                               | per gap: `joints`, `frames` (i0, i1), `missing_s`, `bridge_s`, `kind` (short/long vs `short_gap_s` = 0.150); `kp_true`                                      |
| SYN-07 | SYN-05 motion sampled on VFR times (default 30 fps then 10 fps, like the F-VID VFR video; or seeded jitter)                                                                             | `dt` [s], `is_vfr`, `speed[g](t)` at the real times [Λ/s]                                                                                                   |
| SYN-08 | SYN-05 motion; all L/R pairs exchanged in `swap_frames` (default two runs of 3 frames)                                                                                                  | `lr_swap_mask (T,)` bool, `lr_swap_intervals` [frames]                                                                                                      |
| SYN-09 | pinhole camera: person walks from depth Z0 to Z1 after a 1 s standing reference; image scale ∝ 1/Z, feet on the ground plane; no true hip-height change                                 | `scale_px(t)`, `reference_interval` [s], `lambda_take` [px], `expected_hA(t)`, `expected_hB(t)` [Λ], their ranges, `true_hip_height` (constant, body units) |
| SYN-10 | reference = `raise_lower`; query = same poses re-timed by a monotone warp, `t_q = W(t_r)`, `W' = k(t_r)` (default k from 0.8 to 1.25); optional translation / scale offset of the query | `t_ref_of_query (Tq,)` [s], `rate_k` = dt_query/dt_ref (Appendix C.4 ρ) at each query sample, `same_shape=True`                                             |
| SYN-11 | ref = `raise_lower`; query = `open_close`; plus a same-action variant (small warp + noise)                                                                                              | `action_ref`, `action_query`, `same_action=False`, `variant` (a third `SynthSequence` of the ref action)                                                    |
| SYN-12 | 2–3 people; the target walks out of frame and comes back after `absent_s`; a distractor crosses near the target; detection order shuffled per frame (seeded)                            | `person_id (T, N)`, `target_id`, `absent_intervals` [s] and frames, `crossing_interval`; helper `expected_target_lost(max_lost_s)`                          |

Motion model: `raise_lower` (arms rise in front to shoulder height and lower, knees bend slightly — Taiji
"commencing form" shape) and `open_close` (arms open sideways and close). Both are smooth functions of φ, so speeds are
well defined everywhere and exactly 0 inside pauses. The body template is defined once in units of L (mid-hip origin);
segment lengths stay constant within a scenario except where the scenario changes scale (SYN-09) or is a projection
effect stated in the docstring (knee bend in front view).
