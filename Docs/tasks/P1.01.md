## 1. Analysis

**Goal:** a guide that records the coaches' current review workflow and its time cost first, and shows the three
metric sketches only afterwards, so that the sketches do not shape the answers (plan row: open questions first, then the
3 sketches). Its output feeds P1.03 (needs, keep/replace per metric) and P1.08 (baseline times for the pilot targets).

**Agent role:** draft the guide and the three sketch cards from `TECH_WORKFLOW_V1.md` Appendix B; O edits and owns it.
The agent does not interview anyone.

**In scope:** question list in a fixed order; three sketch cards; a time-measurement block; note-taking rules that match
the P1.02 template; a privacy statement read at the start.

**Out of scope:** running the interviews (P1.02); deciding which metric stays (P1.03); any threshold or "good / bad"
value (none exists: AGENTS.md §5.5); audio recording (default: notes only).

**Output:** `Docs/discovery/interview_guide.md`, in Vietnamese (the interviews are in Vietnamese). The plan row writes
`discovery/interview_guide.md`; on this repository the folder is `Docs/discovery/` (see Q1).

**Existing docs read:** `IMPLEMENTATION_PLAN_V1.md` §5, G00; `WUSHU_TAIJIQUAN_MASTER_PLAN_V3.md` Phase 00;
`TECH_WORKFLOW_V1.md` §3 W0, W7, Appendix B; `WUSHU_TAIJIQUAN_MASTER_PLAN_CORRECTED.md` (P00 deliverables).

**Constraints that apply:** AGENTS.md §5.9 (coaches appear as H1..Hn, no real names or contacts in git), §5.12 (domain

## 2. Plan

**Guide structure (about 57 minutes):**

| Part | Min | Content |
| ---- | --: | ------- |
| 0 Opening | 5 | purpose, notes only, pseudonym H1..Hn, right to skip a question |
| 1 Background | 7 | years teaching, level taught, class size, who films whom today; which version of the 24-form they teach, how they name and divide the movements, how many repetitions (input for P1.04) |
| 2 Current review workflow | 15 | steps from "student sends a video" to "feedback given", minutes per step, tools used |
| 3 What the coach looks at | 5 | open: what do you check first in a 24-form take; which parts are hardest to review |
| 4 Pain points | 5 | open: what costs the most time or goes wrong most often |
| 5 Wishes | 5 | open: what would a useful tool give you (before any sketch is shown) |
| 6 Three sketches | 10 | hip-height variation; trunk lean in the image plane; tempo and pauses; same four questions each |
| 7 Constraints | 3 | cameras, space, devices the coach can use |
| 8 Availability | 2 | hours per month for a pilot (feeds P1.08 and G00) |

**Sketch cards:** each has one sentence on what it measures, one on what it shows, one on what it cannot tell (single
camera, 2D, needs a suitable view). No numbers that look like thresholds. The four questions: would you use it in your
review; what would make it wrong; which number would you not trust; keep, change or drop.

**Steps:**

1. Re-read the sources above against the current Appendix B (the cards must match it).
2. Draft the guide (parts 0–8, cards, privacy line).
3. O edits (language, tone, order).
4. One coach reads it as a trial (20 minutes) and marks unclear questions.
5. Final version; link to the P1.02 note template.
